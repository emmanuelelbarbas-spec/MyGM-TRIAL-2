# WWE Universe Ranking Manager 2.0

Aplicación web local (HTML/CSS/JS puro) para gestionar un modo Universo WWE con:

- Gestión de luchadores y Tag Teams.
- Campeones por división RAW/SmackDown.
- Rankings por puntos con movimiento.
- Registro manual de combates y resultado.
- Generación de carteleras semanales y PPV.
- Historial de shows.
- Draft anual y Soft Draft.
- Persistencia completa en `localStorage`.

## Uso

1. Abre `index.html` en tu navegador.
2. Carga luchadores en **Gestión de Luchadores**.
3. Administra campeones/rankings y registra combates.
4. Genera shows desde **Carteleras**.

No requiere internet ni backend.
