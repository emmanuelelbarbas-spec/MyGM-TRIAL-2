# WWE Universe Ranking Manager 2.0

Aplicación web local (sin backend) para gestionar rankings, campeones, combates y carteleras de RAW y SmackDown.

## Uso
1. Abre `index.html` en tu navegador.
2. Registra luchadores y campeones.
3. Gestiona rankings, combates, shows semanales y PPV.

## Persistencia
Los datos se guardan automáticamente en `localStorage` bajo la clave:
`wwe_universe_manager_v2`.
